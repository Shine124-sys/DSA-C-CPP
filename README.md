## Introduction

This repository contains **hard-level DSA problems** curated from various sources like LeetCode, Codeforces, HackerRank, GeeksforGeeks, and more. Each problem is designed to strengthen your understanding of advanced algorithms, data structures, and problem-solving techniques.

## Purpose

- To provide a structured approach to tackle hard DSA problems.
- To improve problem-solving skills and prepare for competitive programming contests.
- To serve as a personal or community resource for learning and practice.

The repository is organized based on DSA topics:

- **Arrays & Strings**  
- **Linked Lists**  
- **Stacks & Queues**  
- **Trees & Binary Search Trees (BST)**  
- **Graphs**  
- **Dynamic Programming (DP)**

- **Backtracking**  
- **Heap & Priority Queue**

- **Segment Trees & Fenwick Trees (BIT)**  
- **Trie & Advanced Data Structures**

## Problem Structure

Each problem folder/file contains:

1. **Problem Statement:** Description of the problem.  
2. **Input/Output Format:** Example inputs and expected outputs.  
3. **Solution:** Well-explained approach with code (C++, Java, Python, or preferred language).  
4. **Complexity Analysis:** Time and space complexity.  
5. **Notes / Insights:** Tips, tricks, or alternate approaches.
